- www.wikipedia.org = IPv6 = 2a02:ec80:300:ed1a::1
- de.wikipedia.org = IPv6 = 2a02:ec80:300:ed1a::1
In meinem Fall, haben die beiden Seiten die selbte IPv6 Adresse.
Aber sie können auch ander IP Adressen haben, je nachdem wo Standort oder der Server ist. Die Domain, der Name der Website, dient dazu, dass sich der Server nicht alle IP Adressen merken muss.


### nr 5

1. Eingabe: Ich gebe im Browser www.logineo.de ein. Das ist die URL
2. Verarbeitung: Die DNS Auflösung, übersetzt den Namen der Domain in die IP-Adresse. Dadurch weiß mein Computer, welchen Server er kontaktieren muss.
3. Ausgabe: Die Umgewandelte IP Adresse wird im Browser als Webside angezeigt.

**Ziele der Datensicherheit auf www.logineo.de.**
- Vertraulickeit: Nur Personene die das Passwort haben, können persönliche Daten sehen
- Integrität: Von mir geschriebene Texte, dürfen nicht von anderen ohne mein Passwort geändert werden.
- Verfügbarkeit: Meine Lehrer können meine Texte runterladen oder auf der Website lesen, wenn ich sie anschreibe und die Texte freigebe.
